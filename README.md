# LonePanel

纯客户端 iOS 运维 App，通过 SSH / SFTP 直连服务器执行命令与管理文件。服务器端零安装，所有面板能力由 App 本地拼装命令远程执行。

- 语言：Swift
- UI：SwiftUI + iOS 26 Liquid Glass 设计语言
- 最低部署：iOS 26.0
- 包管理：Swift Package Manager（SwiftNIO SSH + swift-crypto）
- Bundle ID：`com.lone.lonepanel`

## 当前状态

五个 Tab（网站 / Docker / 数据库 / 文件 / 设置）可切换；网站/Docker/数据库仍为空壳。
设置模块已实现第一刀「我的服务器」：服务器列表、默认/当前标注、左滑编辑/设为默认/删除、添加/编辑表单、真实 SSH 测试连接、凭证存钥匙串、临时切换仅当前进程有效。
文件模块的视觉与交互对齐 iOS 26/27 系统「文件」App：
- 进入规则：**导航栈底就是默认目录**。冷启动/切服务器时，栈底（`rootPath`）设为该服务器在 `DefaultDirectoryStore` 的默认目录，未设则是真正的根 `/`；此时 `navPath` 为空，标题显示服务器名（真根）或默认目录末级名。设了默认目录后，它即为栈底——**没有返回箭头、无法左滑再向上**（真根之上的目录不再可达），主标题显示当前所处目录名。导航栈与连接状态存放于**单例 model，跨 Tab 切换存活**：切到其他页再回来**停留在离开前的目录**。**再次单击当前「文件」Tab → 回栈底 = 默认目录**：iOS 26 的 TabView 会把嵌套 NavigationStack **系统级 pop 到栈底**，无法取消；由于栈底本身已设为默认目录，系统 pop 的结果天然就是默认目录——因此**彻底删除了过去所有自定义 binding 拦截 / 恢复意图 / pop 检测 / 代次 / 0.4s 兜底等对抗系统的补丁代码**，`TabView` 回归普通 `$selection`，`ContentView` 不再认识任何具体模块。若用户点了标题菜单首项「服务器名称」回到真根 `/`，栈底即变为 `/`，此后点当前 Tab 落点也为 `/`（语义一致）。切换服务器同样回新服务器的默认目录；「设为默认访问目录」后归位到新默认目录栈底。每级目录页**首次加载前显示加载态**而非空白，杜绝「跳到空白页」。底部 TabBar **恒显**：不启用 iOS 26 的滚动收起行为，五个 Tab 在文件列表滚动时始终可见。已配置服务器但尚未连上时显示原生加载动画，未配置服务器才显示「未连接」提示；从后台返回前台时**静默重连**：保留切出时的界面快照与导航层级，不切到全屏「正在连接」，仅在**返回按钮原位**显示一个同等大小的循环转圈（连接是非确定过程，不用线性进度条），重连成功后刷新当前列表，**失败则弹窗提示「服务器连接失败」**。
- **整行可点**：列表/网格中每个条目（文件夹与文件）由系统原生 `NavigationLink`/`Button` 承载，整行都是点击热区，不是只有文件名可点。
- 导航：NavigationStack 逐层 push，左上角**系统原生返回箭头**（根页面不显示、子层级显示、多选态隐藏）；标题下拉为**系统原生 Menu**：**首项恒为当前服务器名称**，点击回到服务器真正的根目录 `/`（用于重新挑选默认目录）；其余层级**从栈底（默认目录）起列**，不再展开 `/` 到默认目录间的祖先，当前项打勾、点击跳转，主标题始终显示当前所处目录名；与右上 ⋯ 同为原生控件；⋯ 菜单含选择/新建文件/新建文件夹/**上传文件**/粘贴/排序/视图切换/显示隐藏/默认目录/重连。右上 ⋯ 在正常态与搜索态都常驻。**上传文件**改用 UIKit `UIDocumentPickerViewController`（`fullScreenCover` 呈现，可多选）：delegate 回调绑定在 Representable 的 Coordinator 上，**不随选文件时 App 进后台、切回时视图重建而丢失**（这正是过去「选完没反应」的根因）；`asCopy: true` 让系统把文件复制进 App 沙箱，返回可直接读取的 URL，绕开 iOS 26 security-scope 读取失败；选中后逐个上传到当前目录，复用批量进度 HUD，上传后清理沙箱临时副本；选择器打开期间抑制回前台静默重连（否则连接被替换会导致上传中断），完成后刷新列表并明确提示成功/失败个数与原因，取消选择不打扰。
- 列表 / 图标网格两种视图，行高/间距/圆角/分组全走系统 List 默认，系统图标按类型着色并与两行文字等高（列表图标 34pt），图标与名称间距 20pt；下拉刷新。搜索采用**系统原生 `.searchable`，挂在每一级目录页上**（配 `isPresented` + `.searchFocused`）：系统为根页与每个子页**各自提供一个原生放大镜**，点开即在当前页呈现搜索框——根治过去「搜索栏只挂导航栈、子页点自定义放大镜却不出搜索框、按钮反而消失」的问题；不再有任何自定义放大镜，**杜绝双放大镜**。各页搜索状态独立、互不串味，切层级随页面退出自然收起；配 iOS 26 的 `.searchToolbarBehavior(.minimize)` 让未聚焦时收缩为放大镜、消除列表顶部常驻灰色搜索条。点系统放大镜后的**键盘弹出与输入框聚焦全部由系统处理**，关闭搜索时清空本页关键词。右上更多按钮为系统裸三点 `⋯`（不套圆圈），搜索态下也不消失。视图模式/排序/升降序/显示隐藏文件等设置**按全局持久化**，冷启动自动恢复。
- 单击目录进入下一级，单击文件走系统 QuickLook 全屏预览；**不支持在线预览的类型（ZIP/7z/rar/gz 等归档与未知二进制）会先提示，确认后再下载并打开系统分享面板**，下载进度在该文件行底部以系统线性进度条显示；长按上下文菜单（顶部拷贝/移动/[共享]快捷三连 + [快速查看]/获取信息/重命名/删除，方括号项仅对文件显示，因目录无法作为单文件预览或分享），左滑重命名/删除/移动。删除确认用**居中圆角方形系统 alert**（无下拉箭头、不误指文件）。
- **批量传输进度**：粘贴/移动/复制多文件或大文件夹时显示原生磨砂 HUD。单文件复制有准确总字节时，**进度条按已传字节连续渲染**（修复过去按项数导致进度条一直空白的问题）；文件名在左、**已传 KB 在右**实时刷新；多文件/目录按项数渲染并同样显示已传字节；SFTP 逐块写回汇报字节增量，SSH 单命令回退显示不确定进度，杜绝界面长时间无变化的误解。
- **拷贝→粘贴**：拷贝写入跨页面共享的剪贴板，进入目标目录后从 ⋯ 菜单粘贴（多选底栏不显示粘贴按钮，避免与选中项语义混淆）；粘贴保留剪贴板可连续使用，切换服务器/单击 Tab 回根时清空；粘贴到源项所在目录会给出提示，避免覆盖自身。移动仍用目标目录选择器。
- 多选态：顶部「全选/取消全选 + N 项 + 完成」（完成为蓝底白色大勾圆角按钮），底部 Liquid Glass 工具条采用**图标+文字的大按钮**（约 52pt 高、均分宽度，便于拇指点击）：移动/拷贝/删除 + **共享（仅当勾选的全是文件时才出现，含任一文件夹即隐藏）**（无粘贴、无冗余的「更多」按钮）；删除后自动退出多选态；按名称/种类/日期/大小排序与升降序；显示隐藏文件开关；删除系统危险路径（/etc、/usr 等）二次确认。
- 「获取信息」面板（系统 Info 风格）展示种类/大小/修改日期/权限/属主/位置，0 字节文件显示「0 KB」（不用系统默认英文 "Zero KB"）。**文件夹不显示无意义的 STAT size**，改用 SSH `du -sk` + `find` 命令测得**真实磁盘占用、文件数、子目录数**（加载中转圈，服务端禁用 exec 时显示「无法获取」）;分享走系统分享面板（支持多选一次分享多文件）。
- **文件操作 SFTP 优先 + SSH 命令回退**：移动优先 `SSH_FXP_RENAME`、复制/粘贴用 read+write 递归（含目录，目标已存在则 `SSH_FXP_STAT` 探测后合并、跳过符号链接、避免复制到自身）；纯 SFTP 失败时回退 SSH `mv -f`/`cp -Rf`。**删除优先 SSH `rm -rf`**（一条命令删掉含非空目录的全部目标，规避 SFTP RMDIR 需空目录及长请求遇重连易失败），服务端禁用 exec 时回退纯 SFTP 递归删除（先子项后自身、软链按文件删）。新建空文件用 SFTP `creat|trunc|write` 打开即关。SFTP v3 协议自实现，零新增依赖。压缩因依赖服务端 `zip` 命令暂不提供。
- 菜单内容（上下文菜单/⋯菜单/批量菜单）按项目需求自定义，整体视觉与交互逻辑对齐系统文件 App。

## 目录结构

根目录平铺 `Core` 与五个平级模块，无 `Modules` 中间层。每一层都遵循同一规则：一个 Core 全局目录 + 若干平级功能模块；Core 只放本层两个以上模块共用的东西，模块私有物留在模块内。

```
LonePanel/
├── App/                          顶层组装层
│   ├── LonePanelApp.swift        @main 入口
│   ├── TabRegistry.swift         Tab 注册表（唯一登记具体模块处）
│   └── ContentView.swift         遍历注册表装配 Tab
├── Core/                         根级全局（五个 Tab 共用）
│   ├── Navigation/TabModule.swift / TabNavigationCenter.swift（Tab 重选回根）
│   ├── Theme/                    主题、共用空壳视图
│   ├── Session/                  ServerConnectionInfo / ServerSession（连接快照与单例）
│   ├── SSH/                      SSHSession（真实握手与 exec）、私钥解析、subsystem 子通道
│   ├── Keychain/                 凭证存取
│   ├── Logging/                  预留
├── Website/                      模块出口 + 空壳 + 内部 Core 与子模块占位
│   ├── WebsiteTab.swift / WebsiteView.swift
│   └── Core/ PHP/ NodeJS/ ReverseProxy/ Certificate/ NginxEditor/
├── Docker/    DockerTab/View + Core/ Containers/ Images/ Compose/
├── Database/  DatabaseTab/View + Core/ MySQL/ PostgreSQL/ Redis/
├── Files/     FilesTab/View
│   ├── Core/        SFTP v3 客户端与协议、默认目录持久化、文件类型/排序
│   ├── Browser/     原生文件浏览器（Model + View + 逐层导航/工具栏/目标选择器）
│   └── Detail/      获取信息面板 + 系统分享封装
├── Settings/  SettingsTab/View
│   ├── Core/       Server 模型、列表落盘、具体会话实现
│   └── Servers/    我的服务器列表页、添加/编辑表单
└── Resources/Assets.xcassets/
```

**依赖方向**：功能模块 → 本层 Core → 根 Core；平级模块互不依赖；下层不反向依赖上层；根 Core 不依赖任何模块。App 层是唯一组装者。

**可插拔**：删除任意模块目录 + 删除 `TabRegistry.modules` 中对应一行，项目仍可编译。

## 本地运行

需要 Xcode 26（含 iOS 26 SDK）。

```bash
open LonePanel.xcodeproj
# 选择 iOS 26 模拟器，Cmd+R 运行
```

首次打开 Xcode 会自动解析 SPM 依赖（SwiftNIO SSH）。

## CI / 构建

推送 tag 触发 `.github/workflows/build.yml`，在 `macos-26`（Xcode 26）上构建未签名 IPA 并发布到 Release：

| tag 前缀 | 示例 | 构建类型 | Release 标记 |
|---|---|---|---|
| `t` | `t1.0.0` | 测试构建 | pre-release |
| `v` | `v1.0.0` | 正式构建 | 正式版本 |

产物命名：`LonePanel-<版本>-<构建时间UTC>-<channel>-unsigned.ipa`。未签名 IPA 可通过 AltStore / SideStore 侧载安装。
